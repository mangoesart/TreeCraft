    Saving and exporting

    Save your work as a TreeCraft file and export meshes for your game.

    Read time 1 minuteTreeCraft 0.1.0 Beta

    Saving your tree

    TreeCraft saves trees in its own text format with the .tctree extension. The file keeps everything:

    • every generator setting, including the faint ones not used yet
    • materials, with their settings and texture file names
    • leaf meshes, with their levels, outlines, anchors and colours
    • scene objects
    Command Shortcut What it does
    New Ctrl+N Starts an empty tree.
    Open Ctrl+O Opens a .tctree file.
    Save Ctrl+S Saves to the current file.
    Save as Ctrl+Shift+S Saves to a new file.
    Save incremental Saves a numbered copy (tree_001, tree_002 and so on) next to the current file.
    Close Ctrl+W Closes the tree.

    Recent files remembers the last 16 trees you opened.

    If the tree has unsaved changes when you close it, start a new one or open another, TreeCraft asks whether to save:

    • Yes saves first.
    • No discards the changes.
    • Cancel keeps the tree open.

    Exporting for your game

    Export (in the Post group, or File > Export mesh, Ctrl+E) writes the tree as a Wavefront OBJ file with positions, texture coordinates and normals. Each material gets its own group in the file, so your game engine can give each part its own material.

    You can also export a single leaf level from the Meshes tab, and render images of the tree. Export image sequence saves 36 pictures in one full turn around the tree.

    Units

    Tools > Scene unit conversion rescales the tree between units: feet to metres (× 0.3048), inches to centimetres (× 2.54) and metres to centimetres (× 100).
