    Building a tree with generators

    Grow a tree from Tree, Trunk, Branch and Leaf nodes in the Generation tab.

    Read time 3 minutesTreeCraft 0.1.0 Beta

    You build every tree in the Generation tab of the dock. Each circle in the graph is a generator. Lines join each generator to its parent. Read the graph from the bottom up: the Tree node sits at the bottom, with the trunk, the branches and finally the leaves above it.

    Grow your first tree

    1. Select the Tree node at the bottom of the Generation tab.
    2. Choose + Add (or right-click the graph) and pick a trunk. A trunk grows from the ground.
    3. Select the trunk node and add a branch generator. Branches appear along the trunk.
    4. Select the branch node and add a leaf generator. Leaves cover the branches.
    5. Click any node to see and change its settings in the Properties panel.

    The small number on each link shows how many parts the generator above it made: for example, 1 trunk and 220 branches.

    To keep a big graph tidy, generators can sit inside a named frame, such as "Right branch" in the picture above.

    Working in the graph

    To do this Do this
    Select a generator Click its node.
    Add a generator Select its future parent, then choose + Add or right-click the graph.
    Move a generator to a new parent Drag from a node's socket onto the new parent (or Shift+drag the node onto it).
    Open more options for a node Right-click the node.
    Try a new random tree Choose Randomize in the dock's toolbar.

    The Add menu lists TreeCraft's generator types by name (trunks, branches, leaf meshes and more). Each entry makes the closest generator TreeCraft has, named after the entry. Entries that TreeCraft can't build yet say so. From file... loads generator settings from a template file.

    New generators start plain

    A generator you add starts with neutral settings, so you can see exactly what each setting does as you change it:

    • no noise, kinks or gravity
    • no random variation in length, angle or radius
    • no flare, droop, fold, curl or twist
    • no material, so it draws in plain grey

    The generator types

    Tree

    The root of the graph. Its Shape radius (10 by default) sets the overall size used by global settings.

    Trunk

    Grows straight up from the ground. A typical trunk is 25 units long with a radius of 1. Its start angle of 0.5 means vertical. Trunks taper toward the tip and can flare at the base.

    Branch

    Grows from a trunk or another branch. First and Last set where along the parent the branches may appear, from 0 (the base) to 1 (the tip). Length and radius can be fixed values or a share of the parent's (for example 40% of the parent's length).

    Leaf

    Places leaf cards on branches. Each leaf uses a mesh from the Meshes tab and a material from the Materials tab. Leaves can droop, fold along the midrib, curl along their length and turn toward the sky.

    A Leaf generator placed under another Leaf generator grows one leaf on each green anchor of the parent leaf's mesh. This is how you make clusters and compound leaves. See Leaf meshes and the cutout editor.
