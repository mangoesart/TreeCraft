    Installing and running

    Build TreeCraft on your computer and start it.

    Read time 1 minuteTreeCraft 0.1.0 Beta

    TreeCraft is a desktop program written in Rust. You build it once from its project folder, then start it like any other program.

    Build TreeCraft

    1. Install the Rust toolchain (from rustup.rs) if it isn't on your computer yet.
    2. Open a terminal in TreeCraft's app folder.
    3. Run cargo build.

    The first build downloads TreeCraft's libraries and takes a few minutes. Later builds are quicker.

    Start TreeCraft

    Run the program the build made: target/debug/treecraft (on Windows, treecraft.exe).

    TreeCraft opens with an empty scene that holds only the Tree node.

    Options for testing

    TreeCraft also understands two options that help when checking a build:

    Option What it does
    --screenshot <file.png> Draws about 120 frames, saves a picture of the window and exits.
    --self-test <file.json> Drives the program with scripted mouse input (orbit the camera, select a node, drag a property, add a node, switch tabs) and writes the results to the file.

    Where TreeCraft keeps your settings

    Your preferences are saved in %APPDATA%/TreeCraft/prefs.txt on Windows. To go back to the default settings, delete this file while TreeCraft is closed.
